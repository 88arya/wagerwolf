# Candidate artwork

Source SVGs handed over during the champion-mark bakeoff, kept out of the repo
root. `design/champion-marks.md` is the log; this is the material.

**These are sources, not assets.** Nothing imports from here. Artwork that is
actually in use has been recoloured to `currentColor` and copied into
`frontend/scripts/icons/`, which is what the icon generator reads — see the
Icons section of `CLAUDE.md`.

|---|---|---|
| `Award.svg` | `app:award` — laurel wreath, Idea 1 | in use |
| `tibbixel-dot-com-30707-svg.svg` | `app:helmet-front` — forward-facing helmet, Idea 4 | in use |
| `Cup.svg` | `app:cup` — Ideas 2 and 3 | scrapped with the trophy direction |
| `Trophy.svg` | `app:trophy` — Idea 2's first artwork | superseded by `Cup.svg` |

| `tibbixel-dot-com-30715-svg.svg` | — | never tried |

Kept rather than deleted because the bakeoff is unfinished and a scrapped
candidate can be recalled; delete the whole directory once a winner is settled
and the survivors live in `frontend/scripts/icons/`.
